# Security Policy

## Scope

VulnCheck is a defensive, passive HTTP security-audit application.

The project intentionally avoids active exploitation features. The scanner should remain limited to authorized, non-destructive HTTP response analysis.

## Reporting a vulnerability in VulnCheck

For a security problem in the application itself, please open a private GitHub security report when the repository supports it. Otherwise, open an issue without publishing sensitive exploit details.

Please include:

- affected component or file
- iOS / Xcode context
- reproducible steps that are non-destructive
- observed impact
- any relevant logs or screenshots

Do not include passwords, private signing material, provisioning profiles, certificates, access tokens, or other secrets in issues or pull requests.

## Research material

Files under `CoreTrust/` are research notes and reference material. They are not a promise that a technique works on a specific device or release.
